# UI再設計（2026-11-23）

画面全体の見直しの記録です。3つの方向を比べ、**A「綴じ帳」を土台に、B「詠唱卓」の「色で対応が分かる出力」を取り入れる**方針に決めました（メンテナー判断、2026-11-23）。検討に使ったモックアップ（Claude のデザインキャンバス）は削除済みです。各案の内容はこの文書に残しています。

## 今の画面の問題（0.2.1 時点）

| 問題 | 影響 |
|---|---|
| 部品のON/OFF（上）と、出来上がったプロンプト・コピー（下）が離れている | 毎回スクロールが必要。「何が出力に入ったか」を目で追えない |
| 7つのタブが2段になり、狭いサイドパネルの上部を占める | 作業領域が狭い。どこにいるかが分かりにくい |
| 同じ見た目のカード（枠・角丸・影）が縦に並ぶ | 主な操作と補助の操作の区別がつかない |
| 出力の文字列が、どのグループ・部品から来たかが分からない | 意図しない部品が入っていても気づきにくい |

## 3つの案

### A. 綴じ帳（バインダー）

- 画面の左端に、バインダーの見出しのような縦書きの色付きタブ（ライブラリ・編集・シャッフル・比較）。設定は下の歯車。
- 編集画面は「グループの中から選ぶ」今の形のまま、カードではなく罫線で区切った1枚の紙にする。
- 画面の下端に濃い色の出力の帯を固定し、大きなコピーボタンを置く。
- 長所: 変更が最も小さく、慣れた操作のまま。短所: 見た目の変化は控えめ。

### B. 詠唱卓（ミキサー卓）

- 暗い配色。出力を画面の上端に固定し、プロンプトの各部分に、元のグループと同じ色の下線を付ける。
- 編集画面はグループごとの行に部品が押しボタン（チップ）として並び、押すとON/OFF。
- 長所: 構成全体と、どの部品がどこに効いているかが一目で分かる。短所: 原文はチップを押さないと見えない。

### C. 一枚の呪文

- 出来上がったプロンプトを大きく表示し、部品を直接押して差し替え・重み・削除。グループの一覧は普段は隠す。
- 部品の追加・プリセット・シャッフルなどは検索窓（Ctrl+K）から呼び出す。
- 長所: 最も静か。短所: できることが画面から見えにくく、初めての人が迷いやすい。作り直す範囲が最大。

## 採用した方針（A＋Bの色）

1. **左の見出しタブ（A）**: 7つのタブを縦書きの見出しタブにし、領域ごとに色を付ける（ライブラリ＝藍、編集＝緑、バリエーション＝赤、比較・実験＝紫、設定＝灰）。選んでいるタブは白い紙とつながる形にする。タブ名・順序・キーボード操作（←→↑↓・Home・End）は変えない。
2. **紙の画面（A）**: 背景は灰緑の机、内容は白い紙。カードの影をやめ、編集画面のグループは罫線で区切る。
3. **出力の帯（A）**: 画面の下端に濃い色の帯を常に表示し、Positive／Negativeの切替、出来上がったプロンプト、コピーボタンを置く。原文の欄とNovelAIのページへの反映は、従来どおり「出力プレビュー」の折りたたみに残す。広い画面では右の列の上部に置く。
4. **色で対応が分かる出力（B）**: 帯のプロンプトの各部分に、元のグループと同じ色の下線を付ける。編集画面のグループ名の横にも同じ色の印を付ける。自由入力は点線。色だけに頼らず、各部分にグループ名の説明（ホバー・読み上げ）を付ける。

## 配色（ライト）

| 名前 | 値 | 用途 |
|---|---|---|
| 机 | `#ECEEE8` | 背景 |
| 紙 | `#FFFFFF` | 内容の面 |
| 墨 | `#1E2330` | 文字・罫線・出力の帯 |
| 藍 | `#2F4B8F` | 主なボタン・リンク・ライブラリ |
| 緑 | `#1F7A5C` | 編集・保存済み |
| 山吹 | `#E9B325` | 出力の帯のコピーボタン |

ダークテーマは同じ役割を暗い面に置き換える。グループの色（出力の帯の下線）は、濃い帯の上で見分けやすい8色（青緑・黄・桃・藤・空・若草・橙・薄紫）を順に使う。

## フォント

この拡張機能は外部からフォントを読み込まない方針のため、日本語・英字ともOSのフォントを使う（`BIZ UDPGothic`・`Hiragino Sans`・`Yu Gothic UI` などを優先）。プロンプトは等幅（`Cascadia Mono`・`SF Mono`・`Consolas` など）。英字の見出し用フォントの同梱は、ライセンス表示の追加と容量を考えて見送った。

## 避けたこと（よくある「既製品っぽさ」）

- 同じ角丸・同じ影のカードを並べるだけの画面
- 装飾だけのグラデーション、見出しの上の英大文字のラベル
- 色だけで状態を伝えること（文字・形も併用する）
