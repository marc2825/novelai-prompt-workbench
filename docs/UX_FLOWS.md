# 画面設計 / 操作フロー

## UIの方針（2026-11-20）

認知負荷を減らすため、常に見える情報は「いま必要な操作と状態」に絞り、説明は求めたときに出す。

- **詳しい説明はホバーで**: 見出しや欄の横の「?」（`InfoTip`）にマウスを乗せる・キーボードでフォーカスする・タップすると表示し、Escで閉じる。本文には1行の要約（`Hint`）だけを置く。警告・エラー・状態表示は常に表示する（隠さない）。
- **段階的に表示**: グループの設定（名前・チャンネル・方式・削除）は「グループ設定」に畳む。NovelAIサイト連携は「接続を確認 → 対象タブ → チャンネル・方法・読取り」の順に必要な項目だけを出す。
- **ボタンの重み**: 主な操作は `primary`（青）、削除などは `danger`（赤い枠）、並べ替えや削除の小さな操作は `icon`、補助操作は `small`。危険な操作だけ確認ダイアログを出す。
- **常に見えるもの**: 機能タブ（折り返して全タブ表示、上部に固定）、元に戻す・やり直す、保存状態のピル、プリセットとの差分状態、出力プレビュー（コピーボタン付き）。
- **2026-11-21の整理**: よく使う操作だけを常に表示し、それ以外は1回の操作で開く。
  - シャッフル: 結果（Shuffle Now・コピー）を最上部に。方式・Seedなどは「シャッフルの設定」、サイト反映・自動シャッフルは「NovelAIのページへ反映」に折りたたむ（自動実行中は開いたまま）。
  - ワークスペース: プリセットは選択・適用・保存だけを表示し、差分・検索・名前変更・複製・削除は「詳細」へ（プリセットタブでは開いた状態）。部品の原文編集（✎）とグループ設定（⚙）はアイコンで開閉。グループ作成はグループがあるとき折りたたむ。
  - 比較: 画像の情報・照合、生成条件の一覧、画像ライブラリを折りたたむ。
  - 出力プレビュー: ライブラリ・ワークスペース・プリセットでは開き、シャッフル・比較・設定では折りたたむ。
  - コピーや編集などの小さな操作は短い表示（「コピー」、アイコン）にし、アクセシブルネームは従来の名前を保つ。
  - テストでは折りたたみを `tests/e2e/helpers.ts` の `openFold` で開いてから操作する（役割ベースの検索は閉じた `<details>` の中を見つけない）。
- **タグの入力補完（2026-11-22）**: ワークスペース・比較の変更案のプロンプト入力欄で、タグを途中まで入力すると入力欄の下に候補（最大8件）を出す。↑↓で選び、Enter/Tabで確定、Escで閉じる。選ばない限りEnterは改行・Tabはフォーカス移動のまま。Ctrl/Cmd/Alt付きのキー（Undo/Redo）とIMEの変換中は横取りしない。入力欄はtextboxのまま `aria-autocomplete="list"`・`aria-controls`・`aria-activedescendant` で候補（listbox、名前「<欄名>のタグ候補」）を指す。候補には辞書／ライブラリの区別、一致した別名、メモを表示する。設定の「入力補完」でOFFにできる（保存される）。
- **タグ辞書（2026-11-22）**: ライブラリタブの「タグ辞書」（折りたたみ）でタグ・別名（カンマ区切り、`、`も可）・メモを追加・編集・削除する。変更は通常の編集で「元に戻す」で戻せる。50件ずつ表示し、辞書内を検索できる。「表記ゆれ・重複の候補」を開くと、ライブラリの原文から表記ゆれ・辞書の別名で書かれたタグ・同じ部品内の重複を一覧する（読取り専用、書換えなし）。ボタン名は「辞書「<タグ>」を編集／削除」で一意にする。
- 実装上の注意: `InfoTip` は `<label>`・見出し・`<summary>` の中に入れない（アクセシブルネームに混ざるため）。`label` はページ内で一意にする（ボタン名は「<label>の説明」）。アイコンだけのボタンには `aria-label` を付け、見た目を短くしてもテストが使う名前を変えない。


現在のタブ順（2026-11-18）: **ライブラリ → ワークスペース → プリセット → シャッフル → 比較 → Experiment Lab → 設定**（作る → 保存・切り替える → 比べる → 設定・バックアップ）。タブは ← → Home End で移動できる（WAI-ARIA tabs、roving tabindex）。初回（ライブラリ・ワークスペースが空）はライブラリタブに3手順の「はじめに」を表示する。ツールバーボタンでサイドパネルが開き、見出しの「広いタブで開く」で同じ画面をタブに開ける。下図は初期の構想図。

## プリセット切り替え

- `制服`プリセット: Hair=黒髪ロング, Outfit=制服, Background=廊下。
- `私服`プリセット: Hair=黒髪ロング, Outfit=カーディガン+ジーンズ, Background=街。
- `水着`プリセット: Hair=ポニーテール, Outfit=水着, Background=プール。

切替前にA→Bの差分を表示し、現在workspaceの変更を破棄する場合は保存/確認する。適用後も元プリセットと辞書項目の原本は無変更。

## 空/失敗UI

- 未登録: `ライブラリに最初のプロンプトを追加`。
- 未接続: `NovelAI画像生成画面を開いてください。コピーは利用できます`。
- 対象DOM不明: `入力欄を安全に特定できません。コピーを使用してください`。
- バックアップエラー: `インポートに失敗したため、元データは変更されていません`。
- PNGメタなし: `設定メタデータを確認できません（画像自体の比較は可能）`。
