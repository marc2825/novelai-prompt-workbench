# 実NovelAIでの確認手順（読取りのみ）

自動テストは模擬ページだけで行っています（[DOM_ADAPTER_CHECKLIST.md](DOM_ADAPTER_CHECKLIST.md)）。この手順は、メンテナーや協力者が**自分のアカウントで、手で操作して**実際のNovelAIの画像生成ページとの読取りを確かめるためのものです（issue #26）。

- NovelAIの[利用規約](https://novelai.net/terms)を守ってください。この手順は画面の読取りだけで、生成・書込み・自動操作は行いません。
- ログイン情報・Cookie・トークン、個人的なプロンプト、ログイン後の画面のスクリーンショットを、Issue・PR・ログに載せないでください。プロンプトはダミーの文字列（例: `test tag one, test tag two`）を使います。
- 結果は「確認した日・Chrome/OS・表示言語・結果」とともに記録し、**確認していない項目を確認済みとして扱わない**でください。

## 準備

1. GitHub Releases の最新版（または検証したいビルド）を [install.md](install.md) の手順で読み込む。
2. NovelAIにログインし、画像生成ページ（`https://novelai.net/image`）を開く。
3. 拡張機能のサイドパネルを開き、出力プレビューの「NovelAIサイト連携」を使う。

## 確認項目

表示言語ごと（英語・日本語）、ログイン前後で行います。

| # | 操作 | 期待する結果 |
|---|---|---|
| 1 | ベースプロンプトにダミーの文字列を入力し、「NovelAIの接続を確認」→ 対象タブを選ぶ | 画像生成ページが1個検出される。自動では選ばれない |
| 2 | Positiveで「サイトの現在値を読む」 | ページの入力と同じ文字列が表示される（改行・空白も同じ） |
| 3 | 除外したい要素（Undesired Content）で同じ操作 | 同じ文字列が表示される |
| 4 | 装飾・マクロを含む入力（例: `{test}`、`||a|b||`）で読む | 読み取らずに「推測しません」等で止まる、または原文のまま表示される（書き換えない） |
| 5 | NovelAIのタブを2つ開き、それぞれで読む | 選んだタブの内容だけが読まれる |
| 6 | ページ内で別の画面へ移動して戻る・再読み込み後に読む | 古い対象として拒否され、接続の確認からやり直せる |
| 7 | 書込みのボタン | 無効のまま（押せない）。サイトの入力・生成ボタンに影響しない |
| 8 | シャッフルの「NovelAIのページへ反映」 | キャラクター欄・生成検知が「非対応」のまま。コピーで使える |
| 9 | 「診断情報をコピー」 | 検出したページ数・各欄の読取り可否と理由・読み取った文字数だけがコピーされる（内容・URLのクエリ・タイトルは含まない） |

## 記録と報告

1. 「診断情報をコピー」の結果と、上の表の結果を、Issueの「実サイト確認の報告」フォーム（`.github/ISSUE_TEMPLATE/site_check.yml`）に貼る。
2. 模擬ページと違う点（ラベルの文言・要素の構造など）があれば、プロンプトの内容を含めずに書く。メンテナーは [DOM_ADAPTER_CHECKLIST.md](DOM_ADAPTER_CHECKLIST.md) に沿って模擬ページと回帰テストに反映する。
3. [release-checklist.md](release-checklist.md) の「NovelAI実サイト」の項目に、日付・Chrome/OS・言語・結果を記録する。

書込みを有効にする検討は、この読取りの確認とNovelAIサポートへの確認（release-checklist）の後に、別途行います。
