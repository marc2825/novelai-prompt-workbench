# NovelAI Prompt Workbench（非公式）

NovelAIの画像生成プロンプトを、**原文を残したまま部品として整理・切り替え・比較する**ためのChrome拡張機能（Manifest V3・サイドパネル）です。データはすべて自分のChromeの中にだけ保存されます。

> NovelAI（Anlatan）とは提携していない非公式ツールです。**画像の生成は行いません**（生成はNovelAI上で自分で行います）。現在はベータ版（0.1.0）です。

## できること

- **ライブラリ**: タグやフレーズを日本語の名前・カテゴリ・タグ付きで登録、検索、複製。
- **ワークスペース**: 部品をグループにまとめ、排他（ラジオ）/複数（チェック）でON/OFF。原文の一部を範囲コメントでOFFにでき、`{}` `[]` `::` `|` マクロ等の記法はそのまま保持。Positive/Negativeを別々に出力してコピー。
- **プリセット**: 構成のスナップショットを保存し、差分を確認してから一括で切り替え（1回のUndoで戻せる）。
- **タグの重み**: 選んだタグだけを0〜2のスライダーで調整（`1.4::blue eyes::`）。
- **シャッフル**: キャラクターの外見は固定したまま、役割・ポーズ・表情・カメラ・左右順だけを入れ替え（Seed付きで再現可能、Shuffle Bag等）。生成回数に応じた切り替えの目安カウント。
- **A/B比較**: 2つの構成を固定し、プロンプト・生成条件の差分と、自分で保存したPNG同士を横並び・重ね合わせ・ピクセル差分で比較。
- **Experiment Lab**: X/Y/Z軸（重み・有無・置換・Seed・Steps等）の条件表を作り、手動生成した画像を登録してグリッドで比較・評価。
- **完全バックアップ**: 全データと画像原本を1つのZIPに保存し、別のChromeプロファイルへ復元。

## できないこと・制限

- **NovelAIのページへの書込み（反映）は無効**です。ログイン後のページ構造とエディタ内部の動作を実機で検証できていないため、現在は**読取りとコピーのみ**です。プロンプトはコピーしてNovelAIに貼り付けてください。
- 生成ボタンの操作、自動・連続生成、NovelAIのAPI呼出し、ログイン情報の取得は行いません。
- シャッフルの「生成完了の自動検知」「キャラクター欄への自動反映」はNovelAI上では使えません（手動で「生成完了を記録（+1）」とコピーを使います）。
- NovelAIが保存したPNG固有の生成情報（Prompt・Seed等）の自動解析は未対応です（標準テキストの表示と手入力に対応）。
- NovelAIのページからの読取りは、表示言語が**英語・日本語**の場合に確認済みです。それ以外の言語や、装飾・マクロを含むプロンプトは読み取らず（推測しないため）、コピーを案内します。
- 対応ブラウザはデスクトップ版Chrome（Chromium系）です。PNG以外の画像形式は未対応です。

## インストール（開発版）

ストア公開前のため、ソースからビルドして読み込みます（Node.js 22.12以上が必要）。

```bash
corepack pnpm install --frozen-lockfile
corepack pnpm build
```

1. Chromeで `chrome://extensions` を開き、右上の「デベロッパーモード」をONにします。
2. 「パッケージ化されていない拡張機能を読み込む」で `.output/chrome-mv3` フォルダを選びます。
3. ツールバーの拡張機能メニュー（パズルのアイコン）で **NovelAI Prompt Workbench (unofficial)** を押すと、サイドパネルが開きます。ピン留めしておくと次からボタン1つで開けます。

更新したときは、`chrome://extensions` で再読み込みし、開いているNovelAIのページも再読み込みしてください。

## 基本の使い方

1. **ワークスペース**タブで「＋ ワークスペース」を作り、グループを追加します。
2. **ライブラリ**タブで部品（例: 名前「黒髪ロング」、原文 `{{black hair}}, long hair`）を登録し、「構成に追加」を押します。
3. 画面下の**出力プレビュー**で結果を確認し、「Positiveをコピー」「Negativeをコピー」でNovelAIに貼り付けて生成します。
4. よく使う組み合わせは**プリセット**に保存し、切り替えます。

まず試したいときは「設定」→「デモを追加」でサンプルが入ります。広い画面で作業したいときは、見出しの「広いタブで開く」（Experiment Labでは「広いタブでLabを開く」）を使います。サイドパネルとタブを同時に開いている場合、片方で保存するともう片方に通知が出るので「他の画面の変更を読み込む」を押してください（そのまま編集すると保存が競合し、保存エラーになります）。

各機能の詳しい操作: [シャッフル](docs/shuffle/architecture.md) / [A/B比較](docs/AB_COMPARISON.md) / [Experiment Lab](docs/lab/README.md) / [プロンプトの扱い](docs/PROMPT_SEMANTICS.md)

## データの保存とバックアップ

- 入力は自動で保存されます。画面上部が「保存済み · この端末のみ」になっていれば保存済みです。保存エラーのときは表示に従って再試行するか、JSONで退避してください。
- 「元に戻す / やり直す」（Ctrl+Z / Ctrl+Y、入力欄の外）は直近30操作まで。パネルを閉じると履歴は消えます。
- データは**このChromeプロファイルの中だけ**にあります。拡張機能を削除すると消えます。

**定期的に「設定」→「完全バックアップをZIPで保存」を実行してください。** 画像原本も含めて保存され、別のプロファイルでも「完全バックアップZIPを読み込む」→ 内容を確認 → 「確認して完全バックアップを復元」で元に戻せます。復元は検証が終わるまで何も変更せず、途中で失敗した場合も既存データは変わりません。

| 方法 | 画像原本 | 用途 |
|---|---|---|
| 完全バックアップ（ZIP） | 含む | 移行・完全な復元（推奨） |
| JSONバックアップ | 含まない | 軽い退避・旧版との互換 |
| Experiment LabのZIP | その実験の画像のみ | 実験の共有（全体のバックアップではない） |

形式と検証内容: [docs/backup.md](docs/backup.md)

## プライバシーと安全性

- 外部への送信、解析、同期は一切ありません。権限は `sidePanel` のみで、NovelAIの画像生成ページ（`https://novelai.net/image`）にだけ読取り用のスクリプトを読み込みます。
- Cookie・ログイン情報・閲覧履歴にはアクセスしません。
- 取り込むファイル（JSON・ZIP・PNG）は上限と形式を検証し、不正なものは取り込みません。

詳細: [PRIVACY.md](PRIVACY.md) / [docs/security.md](docs/security.md) / 脆弱性の報告: [SECURITY.md](SECURITY.md)

## 既知の制限

- 実NovelAIでの書込み・ログイン後UI・キャラクター欄・生成検知は未検証（無効）。
- 完全バックアップは最大2GiB。「追加」モードで同じ画像を共有するデータは統合できません（全置換を使用）。
- サイドパネルと広いタブを同時に使うとき、両方で同時に編集すると後から保存した側が保存エラーになります（データは失われず、JSONで退避できます）。
- 大量のデータ（数千件）では1回の編集ごとの保存に時間がかかり、元に戻す履歴が多くのメモリを使います（目安は [docs/development.md](docs/development.md)）。
