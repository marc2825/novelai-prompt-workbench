# P3-A: プリセット + サムネイル付きライブラリ

1. `Preset`はworkspaceのsnapshot。保存・名前変更・コピー・適用前差分プレビュー・削除・検索。
2. 複数グループを一操作で切り替える（例：制服/私服/水着）。group enabled、selectedMemberId、multi選択状態、freeformがセットで復元。
3. ライブラリの画像プレビューはユーザーの手動アップロードのみ。画像をネット送信しない。Blob/thumbnail別ストア、容量警告、不要画像削除。
4. 本文に含まれる構文や辞書原本を勝手に変更しない。
5. Preset A→B→A一致、辞書後編集でもsnapshotのraw一致、画像削除/破損時の退避UIを検証。
6. P1 JSONはテキストのみのまま。画像付きフルバックアップは別仕様が完成するまで未対応と明記。

結果とテスト実測を`tasks/STATUS.md`へ記録。
