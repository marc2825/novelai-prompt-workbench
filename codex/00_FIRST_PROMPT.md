# Codexへの初回指示（このファイル全文を貼る）

このリポジトリで、NovelAI画像生成向けChrome拡張「NovelAI Prompt Workbench」を実装してください。**要件書を読んで説明だけするのではなく、今回はP0とP1の実装・テストまで進めてください。** 作業の正本は `docs/REQUIREMENTS.md` とし、必ずルートの `AGENTS.md`、`README.md`、`docs/ARCHITECTURE.md`、`docs/DATA_MODEL.md`、`docs/PROMPT_SEMANTICS.md`、`docs/TEST_PLAN.md`、`docs/SECURITY_POLICY.md` を先に読んでください。`codex/01_BOOTSTRAP.md` と `codex/02_CORE_LIBRARY.md` も参照してください。

## 今回のゴール（P0 + P1）

1. WXT + React + TypeScript の初期ひな型を整備し、必要なら現在の互換バージョンに依存パッケージを修正。`pnpm-lock.yaml` を生成する。`pnpm test`, `pnpm typecheck`, `pnpm build` が実際に成功するまで修正。
2. `src/core` の純関数によるコンパイラを、厳密なmulti/exclusive/親enabled/negative/順序/raw保持に対応させ、テストを追加。複数グループで状態が競合しないこと、条件を満たさない項目を誤って送出しないことを確認。
3. `src/data`にIndexedDBベースのライブラリ・ワークスペース永続化を実装。DBスキーマはschemaVersionを管理し、ストレージ例外をUIに表示。初期デモデータはユーザーが明示したときのみ挿入。
4. ReactのSide Panelにライブラリ CRUD（日本語名、説明、カテゴリ、タグ、プロンプト原文）、検索、ワークスペース、グループ作成、排他/複数選択、親ON/OFF、並び替え、ライブプレビュー、コピーを実装。
5. **P1のコメントアウト**（グループ部品ごとの非破壊enabledトグル）を実装。OFF状態でも原文が消えないようにする。P2の「任意テキスト選択範囲コメントアウト」は今回無理に実装しない。
6. ライブラリ、ワークスペース、設定のJSONエクスポート/インポートを実装。形式に `format` と `schemaVersion` を含め、入力サイズ制限・検証・安全なreplace/merge・失敗時不変を保証。P1のバックアップは画像バイナリを含めない。
7. Vitestテストを受入基準 AC01〜AC09とAC12に沿って増強。テスト用のローカルfixtureを用意。実サイトがなくてもP1が利用・確認できる。

## 範囲・禁止事項

- NovelAI本体へのDOM書き込み・生成API呼出し・自動生成・ブラウザのトークン収集は今回実装しない。`entrypoints/novelai.content.ts` は安全なスタブのまま。
- NovelAI固有のコメント構文を想像して使用しない。コメントはワークスペース内部状態だけに保持し、最終出力にはOFF項目を含めない。
- NovelAIの強調 `{}`、`[]`、`::`、マクロ、パイプを勝手に分解/解釈しない。
- ライブラリ原本とワークスペースのスナップショットは明確に分離。後から辞書を更新しても既存スナップショットが勝手に変わらない。
- 実装できない受入基準は `tasks/STATUS.md` に未完として残し、成功したと主張しない。
- 大量の新規ライブラリ導入や状態管理パッケージ追加は、必要性を説明できる場合のみ。
- 既存ファイルの意図を尊重して修正。無関係なリファクタ、秘密情報のcommit、push、デプロイは不要。

## 進め方

まずリポジトリを把握し、実行可能な小さなタスクリストを作る。その後コード編集、テスト、ブラウザで可能な検証を行う。質問待ちで止まらず安全な前提は決めて作業する。作業終了時は修正ファイル、仕様との対応、コマンド別の実測テスト結果、未検証箇所、次に使うプロンプト（P2）を簡潔にまとめてください。
